# 足球赛前分析 Skill (football-cs)

## 概述

这是一个专业的足球赛前分析工具，基于API-Football原始数据和欧洲赔率，通过自主推理分析基本面、阵容、赛程、战术，给出有依据的判断。证据不足时会明确放弃推荐。

## 核心特点

✅ **自主推理分析**：不依赖API预测概率，而是根据原始数据自己推理  
✅ **审慎判断**：证据不足时明确输出"观察"或"无推荐"  
✅ **价值导向**：区分"结果可能性高"和"当前价格有价值"  
✅ **多维分析**：综合基本面、战术、赛程、心理等因素  
✅ **透明推理**：展示完整的推理过程和概率判断依据  

## 使用方式

### 1. 通过命令行调用

```bash
/football-cs 富川1995 vs FC首尔
/football-cs 今天竞彩比赛：曼城 vs 利物浦
```

### 2. 通过机器人调用

支持飞书、企业微信、QQ等机器人发送比赛请求：

**输入格式：**
```
富川1995 vs FC首尔
韩国K联赛：富川 vs 首尔
2026-07-19 18:30 富川1995 vs FC首尔
```

**输出：**
- 完整分析报告（详细版）
- 简版报告（适合机器人推送）

## 数据来源

1. **API-Football** - 比赛数据、球队统计、阵容、伤停、历史交锋
2. **欧洲赔率** - 作为市场观点参考
3. **新闻搜索** - 最新的球队新闻、教练采访

**不使用：**
- ❌ API-Football的`/predictions`概率（不作为分析底稿）
- ❌ 竞彩SP、北单SP（暂时获取不可靠）

## 分析流程

1. **收集数据**：API-Football原始数据 + 欧洲赔率 + 最新新闻
2. **基本面分析**：实力对比、近期状态、主客场、阵容、战意、赛程
3. **自主判断概率**：根据基本面推理真实概率
4. **对比市场**：你的判断 vs 市场观点
5. **计算期望回报**：赔率 × 真实概率
6. **风险评估**：列出可能推翻判断的因素
7. **最终决策**：推荐 / 谨慎推荐 / 观察 / 无推荐

## 输出格式

### 完整报告结构

1. **比赛身份** - fixture_id、赛事、队名、时间
2. **一句话结论** - 推荐状态和方向
3. **基本面分析** - 实力、状态、阵容、战意
4. **你的推理分析** - 展示推理过程和概率判断
5. **赔率分析** - 欧洲赔率和隐含概率
6. **判断vs市场对比** - 差异分析
7. **期望回报计算** - 判断是否有价值
8. **支持因素** - 3-5项证据
9. **反对因素与风险** - 3-5项风险
10. **最终建议** - 推荐方向和强度
11. **数据缺口** - 未确认信息
12. **数据来源** - 来源和时效

### 简版报告（机器人推送）

```
⚽ 比赛分析报告
🏆 赛事 | 📅 时间 | 🏠 主队 | 🚌 客队
💡 一句话结论
📊 基本面
🎯 我的判断 vs 💰 市场观点
💵 期望回报
✅ 支持因素 | ⚠️ 风险因素
🎯 最终建议
```

## 推荐标准

### 期望回报阈值
- **> 1.15**：有较好价值
- **1.10-1.15**：有一定价值
- **< 1.10**：无价值

### 推荐强度
- **强**：证据充分、信息完整、价格有价值
- **中**：证据较充分，但存在部分不确定性
- **弱**：有倾向但风险较高

### 强制放弃推荐条件
- 比赛身份无法确认
- 关键阵容信息缺失（且无法推断）
- 期望回报 < 1.1
- 赔率 < 1.2
- 友谊赛、青年赛或大规模轮换
- 证据不足或冲突过大

## API配置

### API-Football

```bash
# API Key 从环境变量读取，禁止在代码或文档中写入明文
export API_FOOTBALL_KEY=your_api_key_here
BASE_URL=https://v3.football.api-sports.io/
```

> ⚠️ **调用方式**：API-Football 是 REST API，必须用 curl（带 `x-apisports-key` 请求头）或 `requests` 直接调用，**不要使用遵守 robots.txt 的网页抓取工具**（会被误拦截）。

**常用端点：**
- `/fixtures` - 比赛信息
- `/fixtures/statistics` - 比赛统计
- `/fixtures/lineups` - 阵容信息
- `/fixtures/h2h` - 历史交锋
- `/standings` - 积分榜
- `/teams/statistics` - 球队统计
- `/injuries` - 伤停信息

## 注意事项

1. **不是概率播报器**：必须自主推理，不能简单引用API概率
2. **不制造确定性**：不使用"稳胆、必胜"等词语
3. **证据不足时放弃**：宁可不推荐，也不要强行推荐
4. **价值导向**：最可能的结果不一定有投注价值
5. **时效性**：数据可能在赛前2小时内变化，临场前需再确认
